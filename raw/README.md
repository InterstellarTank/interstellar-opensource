# raw/ — сирі джерела

Тут лежать незмінні джерела знань про проєкт: статті, документація, дампи, нотатки, витяги з клієнта.

## Правила

- `raw/` — джерело істини. Агент читає ці файли, але ніколи їх не редагує, не переміщує й не видаляє. Виправлене джерело замінює людина, після чого його можна перезанести у вікі.
- Додавай джерело як `raw/<група>/<назва>.<ext>`; група — на твій розсуд (наприклад `raw/protocol/`, `raw/client-data/`, `raw/articles/`).
- Найкраще працюють `.md` і `.txt`. PDF/DOCX конвертуй у текст перед додаванням, щоб агент читав їх без сторонніх інструментів.
- Не зберігай тут паролі, токени, ключі та інші секрети.
- Великі бінарні файли (клієнт, архіви) не тримай у git; посилайся на них шляхом у тексті.

## Як додати джерело

1. Поклади файл у `raw/`.
2. Скажи агенту «занеси `<шлях>` у вікі» — далі він діє за схемою `## LLM Wiki` у `AGENTS.md`.
